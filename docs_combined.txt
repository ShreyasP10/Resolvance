### 6. Algorithm Design

#### 6.1 Super Resolution

* **Model:** Real-ESRGAN Generator (RRDB) with `in_nc=N, out_nc=N, nf=64, nb=23`, upscale 3Ã— via `Ã—3 PixelShuffle` or 2Ã—+1.5 resize.

* **Forward:** `T = normalize(tile/255) â†’ model(T) â†’ clip 0-1 â†’ uint8`.

#### 6.2 Loss (Training)

```
Loss = L1 + 0.1Â·Perceptual(VGG19) + 0.05Â·SAM
SAM = mean(arccos( dot(pred,gt) / (|pred||gt|) ))
Perceptual = L1(VGG features)
```
Physics bonus: optional NDVI consistency `|NDVI_sr - NDVI_gt|`.

#### 6.3 Tiling & Blending

* Tile 256, overlap 16, stride 240. Weight map 2D Gaussian Ïƒ=overlap/2.
* Accumulator `acc[C,H',W']`, weight_sum `[H',W']`. Stitch `acc / weight_sum`.

#### 6.4 Uncertainty

* MC-Dropout: enable dropout in tail (p=0.2), T=10 passes â†’ `mean, std`. Heatmap `std_norm = (std - min)/(max-min)` viridis colormap.
* Threshold 0.6 std â†’ red overlay warning.

#### 6.5 Metrics

* PSNR `10Â·log10(255Â²/MSE)`, SSIM `skimage`, LPIPS `lpips.VGG`, SAM per pixel mean, ERGAS `100Â·(h/l)Â·sqrt(mean((RMSE/B)Â²))`, NDVI `(NIR-Red)/(NIR+Red)` delta.

def degrade(hr_path: Path, out_lr: Path, scale=3):
    hr = rasterio.open(hr_path).read()  # CÃ—HÃ—W 0.5m
    # Gaussian PSF sigma ~0.8, then downsample via INTER_AREA
    lr = cv2.GaussianBlur(hr.transpose(1,2,0), (7,7), 0.8)
    lr = cv2.resize(lr, (W//scale, H//scale), interpolation=cv2.INTER_AREA)
    # Add Sentinel-2-like noise 1% + clip

    write_geotiff(out_lr, lr, transform_scaled, crs)

#### 5.2 Per-Band Normalize (`kepler/io.py`)

```python
def normalize_to_uint8_per_band(arr: np.ndarray) -> np.ndarray:
    # arr CÃ—HÃ—W float DN
    out = np.empty((C,H,W), dtype=np.uint8)
    for c in range(C):
        band = arr[c]
        valid = band[np.isfinite(band)]
        low, high = np.percentile(valid, [2,98])
        if high<=low: low,high = valid.min(), valid.max()
        out[c] = np.clip((band-low)/(high-low),0,1)*255
    return out
```

#### 5.3 SAM Metric (`kepler/metrics.py`)

```python
def sam(pred: np.ndarray, gt: np.ndarray) -> float:
    # pred,gt CÃ—HÃ—W uint8 -> float 0-1
    pred_f = pred.astype(float)/255; gt_f = gt.astype(float)/255
    dot = np.sum(pred_f*gt_f, axis=0)
    norm = np.linalg.norm(pred_f,axis=0)*np.linalg.norm(gt_f,axis=0)
    angle = np.arccos(np.clip(dot/(norm+1e-8), -1,1)) * 180/np.pi
    return float(np.mean(angle))
```
